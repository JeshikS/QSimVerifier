# Quantum Circuit Mutation Animation PipelineA comprehensive web application for generating and visualizing quantum circuit mutations with survival rates, featuring interactive animations and multi-format output.## 🚀 **Quick Start**1. **Install Dependencies**:   ```bash   pip install -r requirements.txt   ```2. **Run the Web Application**:   ```bash   python app.py   ```3. **Open Browser**: Navigate to `http://localhost:8000`## 📁 **Project Structure**```CircuitAnimation/├── app.py                 # FastAPI web application (main entry point)├── quantum_animator.py    # Core animation engine├── requirements.txt       # Python dependencies├── static/│   └── style.css         # Web interface styling├── templates/│   ├── index.html        # Main interface│   └── results.html      # Results display├── outputs/              # Generated animations (created automatically)└── README.md            # This file```## ⚡ **Core Features**- **5 Quantum Algorithms**: Amplitude Estimation, Grover Search, QFT, VQE, QAOA- **Interactive Configuration**: Algorithm selection, qubit count, survival rates- **Animation Pipeline**: Circuit creation → Breaking → Mutations with survival rates  - **Multi-Format Output**: PNG sequences, HTML slideshows, QASM files- **Session Management**: Unique sessions with organized file structure- **Responsive Design**: Works on desktop and mobile devices## 🧬 **Animation Pipeline**1. **Circuit Creation**: Step-by-step gate addition animation2. **Circuit Breaking**: Gate removal visualization  3. **Mutation Generation**: Create variants with configurable survival rates4. **Export Options**: Download images, QASM files, or view interactive slideshows## 🔧 **Configuration Options**- **Algorithm**: Choose from 5 quantum algorithms- **Qubits**: 2-8 qubit circuits supported- **Survival Rate**: 0.1-1.0 (affects mutation generation)- **Animations**: Toggle creation, breaking, and mutation animations- **Mutations**: Configure number of circuit variants (1-10)## 📊 **Output Formats**- **PNG Images**: High-quality circuit diagrams (150 DPI)- **QASM Files**: Quantum assembly code for each circuit state- **HTML Slideshows**: Interactive presentations with navigation- **Session Archives**: Organized by unique session IDs## 🌐 **Web Interface**The web application provides:- Real-time parameter validation- Progress tracking during generation- Interactive result viewing- Direct file downloads- Session-based organization## 🔬 **Technical Details**- **Backend**: FastAPI with async support- **Frontend**: Responsive HTML/CSS/JavaScript  - **Quantum Computing**: Qiskit framework- **Visualization**: Matplotlib with consistent styling- **Performance**: Optimized rendering with proper scaling## 📝 **Usage Example**1. Select "Amplitude Estimation" algorithm2. Set 4 qubits3. Configure 90% survival rate4. Enable creation and mutation animations5. Generate 5 mutations6. View results and download files## 🛠 **Development**The application consists of two main components:- `quantum_animator.py`: Core quantum circuit animation logic- `app.py`: Web interface and API endpointsAll outputs are automatically organized in the `outputs/` directory with session-based folder structure.
